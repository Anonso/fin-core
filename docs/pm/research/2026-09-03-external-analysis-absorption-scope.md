## 4. 三个候选具体形态

**候选 1 · 强制双边论证**（最贴 owner「提高分析推理水平」的目的）。
现状：第 7 步常被模型做成「列三条利好 + 一句风险提示」。吸收的行为契约：任何
标的结论必须先写满最强多头理由、再写满最强空头理由、互相攻击、最后说明哪边凭
什么赢——从 TradingAgents 辩论提取**行为**，不搬它的多 agent 编排（三道闸①）。
风险：拉长答案，与输出纪律的简洁性冲突；须限定只在「会改变动作」的问询上做，
强度由 owner 拍板。

**候选 2 · 查询复杂度分档 + 先宽后窄**。把「查询经济性」从一句定性升级成可执行
门槛：纯事实 1 个工具 3–10 次调用；方向对比 2–4 个证据源；复杂复盘才全链查证；
外部检索先短宽词扫一圈、评估可得性、再收窄。几乎零风险，人格措辞级改动。

**候选 3 · 问询侧小样本盲评**。这是「提高水平」的前提，也是三道闸②举证倒置的
证据来源——没有它，「我们哪里不如外部项目」永远停在印象。20 个真实问题起步、
五维 rubric（事实/引用/完整性/来源质量/工具效率）、LLM judge 打分；盲评方法可
复用 Daily/deep-read 先例，成本主要在出题与打分。
