# 问询侧盲评 pilot 结果（候选 3 · 首轮）

**日期:** 2026-09-03 · **台账:** `~/.local/state/fin-analyse/consult-blind-eval-20260903/`（0700，含答案原文，不入 git）
**上游:** [2026-09-03-external-analysis-absorption-scope.md](2026-09-03-external-analysis-absorption-scope.md) §7 owner 圈定立项

## 1. 方法

- **题集**：finq 使用日志全部 6 条真实问题（--help 噪音剔除），原样入题；类型覆盖
  持仓 / 标的线 / 星球检索 / 大盘 / 老师锐评参考 / 宏观。
- **双腿**：每题由两个生产入口的无头形态各答一遍——`finqa-claude`（CC
  harness·glm-5.3）与 `finqa-codex`（codex harness·deepseek-v4-pro @
  opencode go，effort max），同工作区、同人格、同 11+1 工具面；每题双腿并行、
  题间串行，单腿 timeout 1800s。12/12 成功，rc 全 0，单题 155–258s。
- **盲化**：双腿产物随机标 A/B（密钥 0600），评分锁定落盘后才解盲。
- **rubric**（开卷前锁定）：事实性 / 引用可溯源 / 完整性 / 来源质量 各 0–5 +
  污染项计数（代码块 / 脚本提议 / 内部标签泄漏 / 工程腔）。工具效率改为客观
  口径（trace 行数/题，12–21 条），不进盲评分以保护盲性。
- **判者**：本 CC 会话（GLM 同族、评测设计者）——**单判者，存在宽松与设计者
  偏置风险**；如采纳为常设方法，建议下轮加第二判者（codex-open 路由）校准。

| codex·ds（finqa-x 腿） | **118** | 29 | 30 | 30 | 30 | 0/12 | ~3.8KB |

**双腿打平。** 差异在结构不在分：

- CC 腿：更长、个人化更深（落到具体持仓、账户算术、自选关联），执行合同要素
  更全（把握度/周期/失效线/反转变量）——q2/4/5 完整性各高 0.5；
- codex 腿：更短、自足性好，q5/q6 **主动联网核验**并给出精确数字与来源时点
  （布伦特 94.65/95.63、CME 66.9%、10Y 4.816%），事实性引用在 q6 反超；
  核验走的是 **codex 原生 web search**（会话日志有 `web_search_call`，q1–q4
  零调用）——外搜工具面不对称：codex 腿=原生+MCP 双路，CC 腿=zhipu MCP
  单路（原生 WebSearch 在 glm 后端未证实可用）。q5 的差异是「值不值得查」
  的判断差（CC 腿明写「关键数字未逐一核验」合规推迟），非能力差；
- **污染 0/12**：12 份答案无一代码块、无脚本提议、无内部标签泄漏、无工程腔。

## 3. 三个发现

1. **底垫污染实证收口（行为半边 + 风格半边）**：两腿合计 12 份真实问询答案，
   零污染。宿主议题（Goose 类建议、Hermes 代替）在本仓的实证部分就此有数据：
   两个现役 harness 都没有产生可测的编码偏向。
2. **问询基线首份**：按本 rubric 现状 ≈ 118/120（98%）。与 owner finq 体感
   （同批题 2y/4n）存在落差——解释：4 条 n 均为 09-02/03 记录，其中长电→
   BUG-024 已施工复验、星球→BUG-012 已闭、宏观/大盘的原始病因不在本 rubric
   四维（是点线面结构与数据缺口），且盲评测的是 09-03 修复后状态。**判者宽松
   与 n=6 是本数的边界，别把它当绝对水平。**
3. **观察名单四候选：本轮均未达举证门槛，维持观察、不施工**（三道闸②）。本
   pilot 无一题因「单边论证/无查询分档/无信息丰富度评级/无双源数字」而失败；
   候选 5 有局部反证（codex 腿 q2 主动双源核对股价），候选 1/2/4 连失效样本
   都没有。四候选想过闸，需要的是**下一次真实使用里的失效样本**，不是再跑
   一轮同质盲评。

## 5. 局限

单判者（GLM 同族 + 设计者）偏宽松；n=6、单日、题型全是系统反复打磨过的类型；
答案分 ≠ 决策质量（无市场真值）；篇幅差（1.4×）是体验偏好，归 owner 权重；
runner 首题前有一次 ~21 分钟后台调度延迟（一次性异常，已记录未解因）。

## 6. 复用

打分 → 解盲聚合。下轮增量：第二判者、把 owner 的 y/n 与盲分并排、失败样本
