## 1. 目标 / 非目标

**目标**：一个 CC 打开即成为"投研顾问"的工作区：人格 + 护栏 + FIN 只读工具 + 跨会话连续性。这是问询产品本体。

**非目标**：不做任何状态存储、调度、服务进程；不做多用户身份（单 principal）；不含交易/写入口（advisory_only）；不建 git 仓（v1 人格文件 ≤3 个、变更低频；P4 稳定后按需再定）。
**v1 客户端收窄（评审 P1-9/B5）**：**仅 CC**。"任意 CLI 打开即连续"的旧表述作废——CC/codex/hermes 各有独立记忆与人格发现，跨客户端连续性不成立；codex 接入方式写入 README 但不在 v1 验收门内；hermes 推迟 P5。§5 连续性承诺按 CC 单客户端表述。

### 3.1 工具使用规则（按框架与评审修订）

1. 任何标的/持仓问题**先调** `read_actual_portfolio` + `read_market_snapshot`。
2. **G 主动参与**：任何偏分析/判断/复盘的问询（"怎么样/怎么看/该不该/要不要"）一律
   **先调 `read_g_context`** 组织分析框架与反证方向（G 主线工具是 `read_g_context`，
   非 teacher_cognition）——不等用户点名"老师怎么看"（框架可观察结果 #2）。纯事实/账户
   查询（"持仓是什么/成本多少"）才豁免。**相关性不确定时默认先调 G**（未见过的主题无法
   在调用前可靠判断相关性，宁可多读一次也不漏主线；评审 P2-4；owner 2026-09-01 口径：
   分析必调 G、纯查询豁免——废除原"组合整体回顾/纯大盘不调 G"豁免）。
3. ZSXQ 优先：ZSXQ 衍生的分级文章/研报总结经 `read_ready_evidence` 获取（server 自动补当前 as_of）；只补查会改变动作的外部证据。
4. 持仓未更新默认连续（框架§八），不提示快照过期、不要求刷新。
5. 工具不可用时按框架§五：基于最大可得信息给条件化主动作 + 失效条件，不倾倒缺口清单、不默认"无动作"。**缺口纪律（评审 P1-10）**：正式持仓/成本/数量缺失时**禁止输出具体仓位数字与整手换算**，动作降级为方向性判断（如"倾向持有，加仓需先核对成本"）+ 失效条件——缺口不许被猜测填满。
6. **时点纪律（评审 P1-21）**：同一轮答案引用的行情与持仓数据时点不一致时（如收盘边界前后），以最旧时点为基准并明示时点差；不拼接"新价格×旧持仓"的静默混合。

## 4. 模型配置（可插拔，L2 泳道）

默认 glm-5.3（所有者拍板，写入本目录启动配置或 README 指引）；换模型 = 换启动方式，人格与工具零改动。**当前事实**（评审 P1-9）：三客户端现配分别为 opus / deepseek-v4-pro / mimo——"默认 glm-5.3"是 v1 要建立的目标配置，不是现状；README 写明 CC 的模型指定方式（启动参数或目录级 settings）。

## 5. 连续性与记忆（owner 明确化，评审 P1-19）

- **记忆 owner = CC 原生 auto-memory**，物理位置按 cwd 编码（`~/.claude/projects/-home-ypk-fin-data-consult-agent/memory/`），不在本目录内；工作区文件不含任何记忆。
- **种子机制**：首次会话按 README 种子指令把框架§八的用户论点（如"云南锗业磷化铟放量"）写入记忆，来源归属标注=用户决定。这是一次性引导，不是自制状态存储。
- **优先级**：typed 工具数据 > 记忆。数字一律重读工具，记忆只存论点/偏好/事件，不存数字；陈旧记忆与工具数据冲突时以工具为准并在答案中更正记忆。
- 家人未来使用 = 各自独立工作区目录 + 各自 `.mcp.json` 数据 root 绑定（P5 再设计）。

## 6. 验收（P1 门 · 冻结题目 + 二分判据）

采用 `fin-private-advisory-decision-framework.md` §11 五场景，具体化为**冻结题目清单**（评审 P2-2：不可判定的措辞全部替换为 trace 可断言条件）：

1. **持仓题**（新会话）："我的持仓怎么样" → trace 断言先调 `read_g_context` 且调用了
   `read_actual_portfolio` → 答案数字与固定快照 digest 一致（owner 2026-09-01 口径：
   分析必调 G；纯查询"持仓是什么"才豁免）。
2. **大盘题**（冻结题目："现在 A 股大盘怎么看，适合加仓指数吗"）→ trace 断言**先调**
   `read_g_context`（owner 2026-09-01 口径：分析必调 G；G 可能返回无相关项，先调语义
   仍成立）→ 无内部缺口标签、无工具名泄漏。
3. **G 相关题**（冻结题目："稀土板块现在怎么看"）→ trace 断言**先调** `read_g_context` → 答案区分老师证据与自身推断。
4. **跨会话连续性**（评审 P2-3）：完成种子会话后**新开会话**问"我的磷化铟论点变了吗" → 答案引用记忆中的用户论点，且 MEMORY.md 有对应条目（人工核对一次）。同会话两轮追问的 resume 属第 1-3 题自然覆盖，不单列。
5. **黄金验例对标**：用框架§十的云南锗业问题问顾问（"磷化铟论点增强了吗，要不要再加一手"），对照 §10 推演按**四项检查表**评分：①动作方向（持有不追）②仓位区间（10-15%）③回撤纪律（15-20% 重决策区）④整手意识。**≥3 项同量级 = 通过**，评分与逐项对照存档。
6. **工具闭集**：CC 会话可见工具恰为 6 个读工具（与 D1 §8 同一核查）。
