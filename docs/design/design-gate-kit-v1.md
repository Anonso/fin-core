## 设计

### 1. 新增唯一新文件 docs/design-gate-packet-template.md，全文如下

````markdown
# 外部审视 packet 模板（AGENTS.md 外部审视节指名的骨架与落盘约定）

> 用法：复制骨架 → 逐槽填写 → 附冻结全文 → `scripts/codex_open.sh exec "$(cat packet.md)"`。
> 权限：落盘前 `umask 077`，目录 0700、文件 0600，落盘后 `stat` 抽查；
>   packet/diff 冻结前人工过目——不含 secrets 与用户数据；diff 只按本次受影响文件
>   allowlist 生成（`git diff -- <paths>`），禁止整仓 diff。
> 落盘：`~/.local/state/fin-analyse/design-gate/<name>-<date>/`
>   固定三件 `packet.md` / `review.md` / `review.stderr`；
>   条件件 `design-doc-snapshot.md`（评审对象为设计稿时）、`retry.ts`（重发时才写，epoch 秒）。
> 预期：3~25 分钟（历史 155s~1360s）；挂死/超时 → 原样重发同一 packet，retry.ts 记重发时点。
> 缓存：同一 packet 原样重发吃完整缓存；跨 packet 仅骨架级有限前缀复用，不作强主张。
> 裁决摘要按 AGENTS.md 外部审视节四件套执行（elapsed/发现/采纳/驳回）。

【外部审视评审 packet · fin-core 冻结包】
触发类型：{设计门（核心设计稿动代码前，规则5）｜吓人 diff 合入前｜外援（同一问题≥2次修复未果）}
背景一句话：{评审对象一句话，含 owner 依据 / BUG 号 / 决策号}

固定四问（逐条回答，每问一节：发现/无发现 + 至少一句依据；不适用须说明为什么）：
Q1 契约破坏：{本次对象的契约面扩展——既有调用方/接口/数据契约是否被破坏}？
Q2 durable state 时序/幂等：{本次对象的状态面扩展——写入/重放/并发/重启语义}？
Q3 引用闭包漏删：{本次对象的引用面扩展——应同步增删改的引用是否遗漏}？
Q4 相对直接 Agent 退化：{本次对象的入口面扩展——公共入口同题是否弱于直接 Agent}？
专项问（可选，≤3 条）：{本次对象特有问题}

评审范围约束：只评{对象}与其直接波及面，不评审仓库其他功能域。
输出格式：Markdown；发现按 P1（必须修）/P2（应修）/P3（可选）分级，
附设计稿节号或 文件:行；末尾「总评」≤3 句。

===== 冻结对象全文 =====
{设计稿全文，或按 allowlist 生成的 git diff + 提交清单}
````
